# Milestone 0: Scaffold, Content Pipeline, Deploy Skeleton

**Branch:** `m0-scaffold` · **Date:** 2026-09-29 · **Status:** complete. Merged to `main` via [PR #1](https://github.com/jiaxingxue/finance-excel-labs/pull/1) on 2026-09-30 and deployed

## What works

- **App scaffold:** Vite 8 + React 19 + TypeScript (strict, `noUncheckedIndexedAccess`), hash routing (`react-router` 8), and a placeholder home page and About page. The home page lists the 12 labs and the content counts, read from the generated data (nothing hard-coded). Styling uses CSS Modules plus design tokens in `src/styles/tokens.css`, with light and dark variants and reduced-motion support.
- **Content pipeline:** `npm run extract` generates 21 files in `src/data/`: 15 sheets, 1,358 cells (668 formulas), 277 assertions, 12 experiments, 171 pattern cells, 15 lessons (Part 0, Labs 1–12, Appendices A–B), the verification notice, and a manifest. `--check` fails on missing, stale, or extra files.
- **Golden cross-check:** the generated workbook (every sheet), assertions, and experiments deep-equal `reference/golden/`.
- **Extractor validation:** it fails with a specific message when a sheet's cell count disagrees with its heading, a count changes, Appendix D/E has more than one JSON block, a lesson formula disagrees with Appendix C, or an assertion or experiment references a cell that doesn't exist. Tests cover each case by mutating the real document.
- **Lab config:** `src/config/labs.config.ts` holds each lab's sheets and primary sheets (PRD §4.5). Tests check that every sheet appears in a lab and that every assertion is owned by exactly one lab.
- **Sub-path deployment:** `npm run build:pages` builds for `/finance-excel-labs/`, and `404.html` is copied from `index.html`. Build metadata (commit, date, version) is injected and shown in the footer and on About.
- **E2E (Playwright):** runs against the production build under `/finance-excel-labs/`. It checks that the home page renders the extracted content, that a `#/about` deep link survives a hard refresh, that unknown routes show a not-found page, and that `404.html` equals the app shell. Every test also fails on console errors or any request to another origin.
- **CI/CD:** `.github/workflows/deploy.yml` runs extract check, notices check, lint, format check, typecheck, unit tests (JSON report), build, and e2e, then deploys to Pages only from `main` when everything passes.
- **Cross-platform:** every script works in Windows PowerShell 5.1 (verified) and bash. Node 24 is pinned via `.nvmrc` and `engines.node: ">=24"`, and `.npmrc` sets `engine-strict`.
- **Licensing:** the full GPLv3 `LICENSE` (canonical text from gnu.org) and a generated `THIRD_PARTY_NOTICES.md` (6 runtime packages, all MIT). CI fails if the notices go stale.

## Decisions and changes made in M0

- All 12 review resolutions are applied and logged in [`docs/OPEN_ISSUES.md`](../OPEN_ISSUES.md). The PRD is updated to v1.3 with a change log.
- D7 is confirmed (content under GPLv3). `docs/DECISIONS.md` is now committed.
- **TypeScript is pinned to 6.0.x, not 7.x.** `typescript-eslint` doesn't support TypeScript 7 yet (OPEN_ISSUES #15).
- **No `tsx` dependency.** Scripts run on Node 24's native type stripping, so the code sticks to erasable TypeScript syntax.
- `lessons/*.json` markdown is verbatim except that the trailing `---` separator between sections is trimmed.
- Added `src/data/notice.json` (for LS-4) and `src/data/manifest.json` (counts and lesson index, so pages don't have to load every lesson to list them).
- Added the `check`, `build:pages`, `preview:pages`, `format`/`format:check`, and `notices` scripts.
- Prettier ignores all Markdown and `.claude/`, so owner-authored docs are never reformatted.
